Rocky Project — 누구나 AI 비서를 쉽게 쓸 수 있는 서비스
한 줄 소개
Rocky Project는 복잡한 AI 도구를 누구나 쉽게 사용할 수 있게 만들어주는 웹 기반 AI 에이전트 플랫폼입니다.

왜 만들었나요?
요즘 ChatGPT, Claude 같은 AI가 정말 똑똑해졌습니다. 그런데 이 AI를 제대로 활용하려면 — 예를 들어 파일을 분석하거나, 코드를 실행하거나, 여러 작업을 자동으로 처리하게 하려면 — 아직도 터미널(검은 화면에 명령어를 치는 도구)이나 복잡한 설정이 필요합니다.

영화 **"프로젝트 헤일메리"**에서 주인공이 외계 친구 Rocky와 함께 지구를 구하듯, 이 프로젝트는 AI라는 똑똑한 친구(Rocky)를 누구에게나 쉽게 연결해주자는 생각에서 시작되었습니다.

해외에는 Manus, Paperclip 같은 비슷한 서비스가 있지만, 한국 사용자가 편하게 쓸 수 있도록 한국어 중심의 쉬운 인터페이스를 제공하는 것이 Rocky Project의 핵심 차별점입니다.

무엇을 할 수 있나요?
1. AI 에이전트 만들기 & 관리하기
마치 직원을 채용하듯, 목적에 맞는 **AI 에이전트(AI 비서)**를 만들 수 있습니다. 각 에이전트는 자기만의 작업 공간을 갖고 독립적으로 일합니다.

"데이터 분석 담당" 에이전트
"문서 작성 담당" 에이전트
필요에 따라 여러 개를 만들어 각각 다른 일을 시킬 수 있습니다.
2. 대화하듯 지시하기
복잡한 명령어 대신, 채팅창에 한국어로 말하듯 지시하면 됩니다. AI가 작업하는 과정을 실시간으로 볼 수 있어서, 무슨 일이 일어나고 있는지 항상 파악할 수 있습니다.

3. 파일 관리 & 결과물 확인
에이전트가 작업하는 파일들을 웹 브라우저에서 바로 열어보고, 다운로드하거나, 새 파일을 올릴 수도 있습니다. AI가 만들어낸 결과물(보고서, 차트, 코드 등)도 한눈에 확인할 수 있습니다.

4. 대화 기록 & 이어서 작업하기
AI와 나눈 대화는 세션(작업 단위)별로 저장됩니다. 며칠 뒤에 다시 돌아와서 이전 작업을 이어서 진행할 수 있습니다. 마치 메신저 대화 기록을 스크롤해서 읽는 것처럼요.

5. 여러 AI 계정 연결
하나의 플랫폼에서 여러 AI 서비스 계정을 연결하고 관리할 수 있습니다. 상황에 따라 다른 AI 엔진을 골라서 쓸 수 있습니다.

6. 안전하게 사용하기
AI가 위험한 작업을 하려 할 때는 먼저 사용자에게 승인을 요청합니다. 각 에이전트의 작업 공간은 서로 격리되어 있어서, 하나의 에이전트가 다른 에이전트의 데이터를 건드릴 수 없습니다.

비유로 이해하기
일반적인 비유	Rocky Project
사무실	웹 브라우저에서 접속하는 관리 화면
직원	AI 에이전트 (각자 전용 책상과 서류함을 가짐)
업무 지시	채팅창에 한국어로 "이거 해줘"
업무 보고	실시간으로 작업 과정이 화면에 표시됨
서류 캐비넷	에이전트별 파일 저장 공간
기존 서비스와 뭐가 다른가요?
Manus / Paperclip	Rocky Project
언어	영어 중심	한국어 중심 UX
사용 난이도	개발자 친화적	비개발자도 쉽게 사용 가능
에이전트 관리	단일 에이전트	여러 에이전트를 독립적으로 운영
대상 사용자	해외 기술 사용자	한국 사용자 맞춤
한마디로 정리하면
Rocky Project는 "AI를 잘 모르는 사람도 웹 브라우저만 열면 AI 비서를 만들고, 지시하고, 결과를 받아볼 수 있는 서비스"입니다.

터미널도, 코딩도, 영어도 필요 없습니다. 그저 무엇을 하고 싶은지 말하면, Rocky가 해냅니다.
